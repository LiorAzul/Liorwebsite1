# אתר תיק העבודות של ליאור ישראל אזולאי

דף נחיתה להצגת התיק עבודות של ליאור ישראל אזולאי, גרפיקאי ועורך וידאו.

## תכונות עיקריות

- עיצוב מודרני ומרשים עם גרדיאנטים ואנימציות
- אזור FutureOS עם סרטוני יוטיוב
- גלריית עבודות גרפיקה
- אזור אלדיו עם אינטגרציה של אינסטגרם
- רשתות חברתיות וקישורים מעוצבים
- כפתור וואטסאפ מרחף לשליחת הודעה מהירה
- תמיכה מלאה במכשירים ניידים

## קבצים

- `index.html` - מבנה האתר
- `styles.css` - עיצוב האתר
- `script.js` - אנימציות ואינטראקציות
- תמונות ווידאו

## איך להריץ

פשוט פתח את קובץ ה-`index.html` בדפדפן כלשהו. האתר לא דורש שרת או התקנות נוספות.

## טכנולוגיות בשימוש

- HTML5
- CSS3 (עם אנימציות, גרדיאנטים ומדיה קווריז)
- JavaScript (לאנימציות ואינטראקציות)
- Font Awesome (לאייקונים)
- Elfsight (לפיד אינסטגרם)

## דברים לשיפור בעתיד

- הוספת גלריה אינטראקטיבית עם אפשרות להגדלת תמונות
- הוספת טופס יצירת קשר מלא
- הוספת בלוג או חדשות
- שיפור זמן טעינה נוסף

## יוצר
